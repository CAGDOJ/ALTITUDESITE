# ALTITUDE — Correção do banco e responsividade (Atualização 06)

Execute primeiro `ATUALIZACAO_05_CORRIGIDA_CARTEIRA_HORAS.sql` no SQL Editor do Supabase. Depois publique os arquivos deste pacote no GitHub Pages.

A correção elimina o erro `column c.liberado_em does not exist`, cria os pré-requisitos ausentes e mantém o fluxo de carteira de horas, solicitação parcial e liberação do PDF pelo gestor.

## Instalação

1. Abra uma nova consulta no SQL Editor.
2. Cole todo o arquivo `ATUALIZACAO_05_CORRIGIDA_CARTEIRA_HORAS.sql`.
3. Clique em Run.
4. Confirme a mensagem `Atualização 05 corrigida aplicada com sucesso`.
5. Publique este pacote no GitHub.
6. Atualize o navegador com limpeza de cache.

## Responsividade

O arquivo `Projeto/2-css/06-responsive.css` e o script `Projeto/4-java/06-responsive.js` corrigem o portal do aluno, sala de estudo, prova, portal do gestor, modais, tabelas, carteirinha, catálogo e menus para celulares e tablets.
