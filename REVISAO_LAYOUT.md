# Revisão de layout — Instituto Altitude

Esta etapa foi limitada a correções estruturais e de consistência visual, mantendo a identidade existente da marca.

## Correções aplicadas

- Cabeçalho público padronizado nas páginas inicial, cursos, login, cadastro, sobre, ajuda, certificados, contrato e privacidade.
- Cabeçalho móvel e menu hambúrguer padronizados.
- Remoção dos deslocamentos fixos que empurravam a logo e os botões para fora da tela.
- Correção da rolagem horizontal nas páginas públicas e nos portais.
- Tabelas dos portais passam a rolar dentro de sua própria área em telas pequenas, sem criar rolagem lateral na página inteira.
- Portal do gestor adaptado para empilhar menu e conteúdo em telas menores.
- Formulário de cadastro ajustado para usar corretamente o cartão previsto no CSS existente.
- Rodapé padronizado, preservando paleta, logo, textos e links.
- Correção de caminhos de CSS incorretos ou ausentes.
- Correção do carregamento de um arquivo HTML como se fosse CSS na página inicial interna.
- Correção dos arquivos de contrato e política de privacidade, que não possuíam estrutura completa de página.
- Remoção de scripts duplicados no portal do gestor.
- Correção de sintaxe do arquivo `Projeto/4-java/index.js`.
- Adicionado fallback com a logo Altitude para a imagem de curso ausente no projeto.

## Arquivos estruturais adicionados

- `Projeto/2-css/base-public.css`
- `Projeto/2-css/base-portal.css`
- `Projeto/4-java/layout-public.js`

## Validações realizadas

- Estrutura HTML verificada em todas as páginas.
- Todos os arquivos CSS, JavaScript e imagens locais referenciados foram conferidos.
- Arquivos JavaScript passaram na verificação de sintaxe.
- Layout estrutural conferido em 390 px e 1440 px, sem estouro dos contêineres principais.

Nenhuma cor, logotipo ou identidade visual principal da marca foi substituída.
